# Milestone 1: sim core (baseline numbers)

Machine: Windows 11 laptop, Intel Arc 140T integrated GPU (ANGLE / D3D11), Chrome 156 driven over CDP, production
build. Stress scene: `?bench`, 60 shots/s through x5 then x3 / x100 gates into continuous grunt waves; ~5,200-5,300
entities drawn on average (both pools near their 3,000 cap), 18 draw calls, ~265K triangles.

## Browser (`npm run bench:browser`, 10 s after 3 s warm-up)

| profile | fps | frame p50 / p95 / p99 (ms) | sim (ms/frame) | render CPU (ms/frame) | GPU (ms/frame) |
|---|---|---|---|---|---|
| phone: 4x CPU throttle, 390x844 @ DPR 2, vsync | 55.5-60.0 over 9 runs, median 59.8 | 16.7 / 17.0 / 17.1-33.4 | 2.2-2.7 | 3.9-5.6 | 5.1-7.7 |
| phone: 4x CPU throttle, unlocked | 152-159 | 5.9 / 11.9 / 16.1 | 0.84 | 3.2 | 3.6 |
| desktop: 1x, 540x960 @ DPR 2, vsync | 60.0 (all runs) | 16.7 / 17.0 / 17.3 | 0.33 | 0.48 | 5.4 (p95 9.7) |
| desktop: 1x, DPR 1, unlocked | 171-313 | 0.6 / 12.4 / 83-174 | 0.07 | 4.3* | 2.9 (p95 6.2) |

\* Unlocked desktop means are dominated by rare 100-400 ms stalls inside `renderer.render`: with vsync and the frame
limit off, the CPU runs thousands of frames ahead and Chrome blocks on the GPU queue. With vsync on, the same build has
max 17.6 ms, so it is an artefact of the unlocked mode. Real headroom for 120 Hz: CPU < 1 ms/frame; GPU p95 ~6 ms at
DPR 1 and ~7-10 ms at DPR 2 on this integrated GPU (tight at DPR 2).

## Headless sim (`npm run bench:sim`)

0.26 ms/tick mean (p99 0.44) at ~5,300 live entities, 1x CPU, Node 24.

## Allocation (V8 sampling heap profiler, 3,600 stress ticks)

1,173 B/tick before fixes -> 41 B/tick after. The per-entity loops allocate nothing. The residual comes from V8
tiering of once-per-tick functions (it gets worse with Maglev disabled), which works out to about one minor GC every
few minutes.

## Profile-driven changes (4x throttle, stress scene)

| change | measured effect |
|---|---|
| `writePool`: sine table + clz32 stack scale + typed per-type params | 2.55 -> 1.1 ms/frame |
| 16-byte `aInst` attribute instead of 64-byte matrices | upload 4x smaller; vsync 4x went 58.5 -> 60.0 median |
| No infinite CSS animation; `contain: strict` HUD pills | removed per-frame style recalc and page-wide layouts |
| Inline grid cell math | `col`/`row` frames gone from the profile |
| Field initializers, slot-claim spawns/events, int RNG | 1,173 -> 41 B/tick |
