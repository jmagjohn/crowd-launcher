# Milestone 2: content, weapons, meta, visuals

## What shipped

- **Campaign, 15 levels** (`src/levels/campaign.ts`), one new mechanic per level: × gate, gate choice, Brute,
  + pulse gate, shields, ÷ gate, − toll, moving gates, swarms, **boss at 10** (the Warden), breather at 11, flip gates,
  limited-use gates, gauntlet, siege. Each first appearance has an intro card on the start screen.
- **Full unit roster in the sim.** Enemies steer toward the launcher inside 30 units of the line, so an unaimed stream
  still meets the front. Swarms weave. The boss plants, telegraphs (a pulsing red blast circle on the ground), then
  releases a shockwave ring. A unit is hit exactly once, on the tick the ring's edge crosses it (a sign change of
  distance minus radius); soldier stacks die and a Brute loses 30% of its max HP.
- **Weapons** (`src/sim/weapons.ts`), bought once and equipped:
  - Blaster: 1×
  - Twin Cannon: 2 muzzles, 1.2× units
  - Scatter Gun: 3-way fan, 1.35× units, poor at threading gates
  - Runner Gun: fires Runners, 1.25× rate, near double speed

  Each weapon has its own launcher model.
- **Upgrades** (`src/meta/upgrades.ts`): Fire Rate, Volley (exact integer extras per shot), Gate Power, Reserves,
  Quick Charge, Brute Power, Siege. Each upgrade costs `c0 · 1.45^k`.
- **Meta** (`src/meta`):
  - Versioned save with migration.
  - Rewards: full on the first clear, then 25% halving down to 5%. Losses pay a consolation share.
  - Fail-forward loss hints, plus a "you can afford X" nudge.
  - Dynamic difficulty: −5% per 3 consecutive losses, capped at −15%, never raised, every step logged.
- **UI:** main menu, level map, shop (Weapons / Upgrades tabs), start screen with intros and the boss tag, end screen with
  coins, pause button, weapon tag, and floating "+24" gate popups.
- **Visuals:**
  - Unit models built from merged primitives with vertex colours, still one draw call per type.
  - Blob shadows that share the unit buffer.
  - A crumbling fortress: pieces break off at HP thresholds, smoke, then collapse on defeat.
  - A weapon-specific launcher with recoil, muzzle flash, aim guide and a Brute-ready ring.
  - Gate frames with animated energy panels.
  - Pooled particles for kills, gate passes, base hits, breaches and shockwaves.
  - Shockwave rings, camera shake, curbs, trees, rocks and hills.
- **Debug:** `?debug` lil-gui panel; `?hide=` GPU A/B flag; `npm run levels` bot table; `npm run shots` screenshots.
- **Tests: 66 passing.**
  - New: save migration and round trip, reward schedule, the assist cap, a win resetting the streak, upgrade cost
    curve, weapon ownership.
  - Weapon fire volume per weapon; exact volley math; difficulty scaling of headcount and HP; the champion lock.
  - The shockwave hits once and deals exactly 30%; shockwave kills are conserved.
  - Determinism and per-tick conservation now run on all 15 levels.

## Performance (stress scene, ~5,300 drawn units)

Measured the same way as M1 (`npm run bench:browser`, production build, Intel Arc 140T, ANGLE/D3D11). Note: during
these runs this machine's display cadence was **56.8 Hz** (an empty page measured the same), not 60 as in M1, so
"full rate" is 56.6 fps here.

| profile | fps | frame p50 / p95 / p99 (ms) | sim / render CPU (ms) | GPU (ms) |
|---|---|---|---|---|
| phone: 4x CPU, 390x844 @ DPR 2, vsync | 56.6 (full rate) | 17.7 / 18.4 / 18.7 | 1.9 / 5.5 | 9.9 (p95 16.9) |
| phone: 4x CPU, unlocked | 59.2 | 16.9 / 32.5 / 45.0 | 2.5 / 8.4 | 11.8 |
| desktop: 1x, DPR 2, vsync | 56.6 (full rate) | 17.7 / 18.5 / 18.7 | 0.4 / 0.8 | 9.3 (p95 16.8) |
| desktop: 1x, DPR 1, unlocked | 154 | (stall artefact as in M1) | 0.1 / 5.9 | 6.4 (p95 12.8) |

**Profile-driven fixes**:

| change | measured effect |
|---|---|
| First pass of the new visuals | GPU 5.4 → 20 ms; phone-4x-vsync 38 fps |
| Models non-indexed at 186 triangles → indexed merge at 64–88 triangles | GPU 20 → 11 ms |
| Blob shadows A/B | 2.5 ms of GPU at DPR 2 |
| Sky texture | a full-screen pass hidden under the ground (an empty scene measured 3.2 ms); replaced with a clear colour |

After the fixes, the phone-4x-vsync p95 went from 35 ms (dropped frames) to 18.4 ms (none).

**Automatic quality ladder** (`src/render/quality.ts`): shadows → DPR steps → visual cap. In the bench run it
correctly did not trigger, since frames were at full rate.

**120 Hz on desktop:** GPU p95 is 12.8 ms at DPR 1, so 120 Hz on this integrated GPU needs the ladder's first step
(shadows off). A discrete GPU has ample headroom.

## Known issues / next

- **Balance is preliminary.** The average bot fails 4, 6 and 14, which is probably bot weakness (gate-path greed plus a
  0.4 s reaction time) as much as level tuning. M3's calibrated bots and band checks will settle it.
- **Real-phone GPU is still unmeasured.** The integrated laptop GPU is the stand-in.
- **Not yet built:**
  - Audio is M4.
  - Procedural levels 16–50 and the balance table are M3.
  - glTF models: the asset-swap layer is ready, no models are loaded yet.
